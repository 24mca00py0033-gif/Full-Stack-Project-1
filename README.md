# Full Stack Project 1

A full-stack e-commerce-style web application with separate Frontend, Admin, and Backend apps. It demonstrates a modern JavaScript stack (React + Vite on the client, Node/Express + Mongoose on the server) and includes UI components, product/cart pieces, API routes, file upload and payments integrations.

## Tech stack
- Language: JavaScript (ES Modules)
- Frontend: React (Vite), Tailwind CSS, react-router-dom, react-toastify, axios
- Admin: React (Vite) — separate admin SPA
- Backend: Node.js + Express, Mongoose (MongoDB), JWT auth, multer/cloudinary for uploads
- Payments: Stripe and Razorpay integrations present in server dependencies

## Highlights / Features
- Separate Frontend (customer-facing) and Admin panel
- Componentized React UI (product list, best-sellers, cart total, search, newsletter, etc.)
- REST-style backend using Express and Mongoose
- File uploads (Cloudinary) and payment provider integrations (Stripe, Razorpay)
- Environment-driven configuration for secrets and API endpoints
- Deployment-friendly config files present (vercel.json)
